# 💻 O que é uma Linguagem de Programação?

Uma **linguagem de programação** é um conjunto de regras e instruções que permite ao programador criar programas capazes de executar tarefas em um computador.

De forma simplificada:

```text
Programador
     ↓
Código
     ↓
Linguagem de Programação
     ↓
Computador
     ↓
Execução das instruções
```

### 🧩 Linguagens de Programação × Linguagens de Marcação

É importante não confundir linguagens de programação com outros tipos de tecnologias.

**Linguagens de programação:**

* C
* C++
* Java
* C#
* PHP
* Python
* Ruby
* JavaScript
* Go
* Lua
* Dart
* Entre muitas outras

**Linguagens de marcação:**

* HTML
* XML
* YAML

**Linguagem de estilização:**

* CSS

Cada uma possui uma finalidade diferente.

## ⚙️ Classificação das Linguagens

As linguagens de programação podem ser classificadas de diferentes maneiras.

### 🔹 Alto nível e baixo nível

As linguagens podem ser classificadas de acordo com o quanto sua sintaxe e abstrações estão próximas da linguagem humana ou do funcionamento do computador.

```text
Alto nível
   ↑
   │  Python
   │  JavaScript
   │  Java
   │  C#
   │
   ↓
Baixo nível
```

De maneira geral, linguagens de **alto nível** oferecem abstrações que tornam o desenvolvimento mais próximo da forma como os seres humanos estruturam problemas.

### 🔹 Compiladas e interpretadas

Também podemos encontrar diferentes formas de execução das linguagens.

* **Compilação:** o código é transformado antes da execução em uma forma que pode ser executada pelo computador.
* **Interpretação:** o código é processado por um ambiente de execução durante sua execução.

> ⚠️ Na prática, essa divisão pode ser mais complexa. Muitos ambientes modernos utilizam técnicas como compilação JIT (*Just-In-Time*).

# 🟨 O que é JavaScript?

**JavaScript** é uma linguagem de programação criada em **1995 por Brendan Eich**, inicialmente desenvolvida para ser utilizada no navegador Netscape.

> ⚠️ **JavaScript não é Java.** Apesar dos nomes semelhantes, são linguagens diferentes.

O nome oficial da especificação da linguagem é **ECMAScript**.

# 🌐 JavaScript na Web

JavaScript é uma das principais tecnologias utilizadas no desenvolvimento da **Web**.

Junto com **HTML** e **CSS**, forma a base do desenvolvimento web:

```text
        🌐 WEB
          │
    ┌─────┼─────┐
    ↓     ↓     ↓
  HTML   CSS  JavaScript
    │     │      │
    ↓     ↓      ↓
Estrutura Estilo Comportamento
```

### 🟧 HTML

Responsável principalmente pela **estrutura e conteúdo** da página.

### 🎨 CSS

Responsável principalmente pela **aparência e estilização**.

### 🟨 JavaScript

Responsável principalmente pela **lógica e comportamento** da página.

# 🖥️ JavaScript fora do navegador

JavaScript não está limitado aos navegadores.

Também podemos executar JavaScript fora deles utilizando **runtimes**, como o **Node.js**.

Isso permite utilizar JavaScript em diferentes tipos de aplicações, como:

* 🖥️ Aplicações de servidor
* 🌐 APIs
* 🛠️ Ferramentas de linha de comando
* 📦 Automação
* 🔧 Ferramentas de desenvolvimento
* 🗄️ Aplicações que trabalham com bancos de dados

---

# 🚀 Por que estudar JavaScript?

JavaScript é uma linguagem bastante versátil e possui uma forte presença no desenvolvimento web.

Ela permite começar desenvolvendo funcionalidades diretamente no navegador e, posteriormente, utilizar ambientes como o **Node.js** para desenvolver aplicações fora dele.

> 💡 **Minha opinião:** JavaScript é uma excelente opção para quem está começando a aprender programação, especialmente para quem deseja entrar no desenvolvimento web.
